# Lid Awake 2.0 · 首个开源预览版

原生 macOS 单按钮合盖防休眠工具，采用 MIT 许可证。

- 首次安装辅助服务授权一次，日常开启、关闭和再次打开无需重复授权。
- 关闭开关、退出或应用崩溃后恢复原来的休眠设置。
- 支持 macOS 13+，Apple 芯片 / Intel 通用构建。

## 下载

推荐使用 `.pkg` 一并安装应用和辅助服务；`.dmg` 包含应用和安装包。`SHA256SUMS.txt` 用于核对下载文件。

## 预览版说明

产物从本仓库源码构建。当前使用本地临时签名，**没有 Apple Developer ID 签名和公证**，macOS 可能阻止打开。请只运行可信来源的软件；也可以审阅源码后自行编译。

本地 41 项完整检查通过，CI 模式 40 项通过并跳过宿主电源偏好对照；GitHub Actions 测试与通用应用构建通过。实际管理员安装、系统重启、Intel 硬件和物理合盖行为尚待对应设备验证。

合盖后内置屏幕仍会关闭。保持通风，留意电量。更换版本或卸载系统服务可能再次要求管理员授权。

源代码与使用方法见 [README](https://github.com/MoFanMon/lid-awake#readme)。
